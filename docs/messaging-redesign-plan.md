# Wathiq messaging redesign

Approved on 16 November 2026. The [messaging specification](../specs/notifications-and-messaging.md) governs mailbox behavior. The approved prototype guides layout and action placement.

## Implementation

1. Use the Wathiq shell and its privilege-aware Navigation sidebar for the three mailboxes. The tabs in the clickable prototypes let reviewers move between mockup screens. Place Compose beside the title, group secondary filters, and show applied criteria. Use standard NiceGUI controls and Wathiq styling. Keep the list and reading or editing pane side by side on desktop, mirror their order in Arabic, and stack the list first on narrow screens.
2. Make unread state, due dates, and action status easy to scan in Inbox. Keep Reply and Forward visible where permitted and group capture and deletion under secondary actions. Give Outbox subject search a prominent position, show the original addressees in each row, and group delivery status, requested receipts, and completion replies. Place Amend action next to the current action state. Keep Drafts editing inline with explicit Save, Send, Cancel, and Discard. Recently deleted drafts open read-only and offer Restore. Retain existing filters, linked-message and resource access, expiry warnings, and retention rules.
3. Show a brief confirmation after a draft save. Offer **Open in Drafts** in the Compose dialog using the returned draft ID. After sending, offer **View in Outbox** in a dismissible notification using the returned envelope ID. Open authorized detail alongside the current list even when its filter or page excludes the item. Remove a successfully sent draft immediately and refresh the listing without waiting to close its editor. Keep the editor and entered values on failure. Reuse the API, draft versions, and send retry semantics.
4. Keep the last applied filters and page per mailbox. Revalidate with bounded, server-authorized requests when revisiting. Use the shared **Messages per page** setting, default 25. Return to the first page when that setting changes and retain submitted filters and Recently deleted mode. Guard list, detail, and dialog responses independently. Use the current unread count and cursor signals. Reuse catalogue strings and merge new localized keys into the sorted, canonical artifacts, retaining curated wording and provenance.
